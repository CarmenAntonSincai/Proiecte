# Atelier de aplicații cu AI

Pagina proiectului: etapele (fișele de lucru), galeria aplicațiilor elevilor pe clase și ghidul de publicare pe GitHub Pages.

## Fișiere

- `index.html` — pagina (nu trebuie modificată)
- `date.json` — conținutul: proiectul, etapele, clasele și elevii cu linkurile lor

## Cum actualizezi pagina

1. Deschide pagina publicată cu `#profesor` la final, de exemplu `https://utilizator.github.io/atelier-ai/#profesor`.
2. Apare „Mod profesor (local)”. Adaugă elevi, editează etape sau clase ca pe pagina obișnuită. Modificările se păstrează doar în browserul tău.
3. Apasă **Copiază datele (date.json)**.
4. În repository, deschide `date.json`, apasă creionul (Edit), selectează tot conținutul și înlocuiește-l cu ce ai copiat. Apasă **Commit changes**.
5. După 1–2 minute, toți vizitatorii văd pagina actualizată. Dacă vrei să golești ciorna din browser, apasă „Renunță la modificări” sau reîncarcă după commit.

Elevii văd pagina fără `#profesor` și nu pot modifica nimic; chiar dacă deschid `#profesor`, modificările lor rămân doar la ei în browser.

## O clasă nouă

În modul profesor apasă **+ Clasă nouă**. Etapele rămân aceleași, fiecare clasă are galeria ei.
